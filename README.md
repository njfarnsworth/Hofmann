# Hoffman-Replication
This repository contains a replication of the employability results from “Dialect prejudice predicts AI decisions about people’s character, employability, and criminality” (Hofmann et al.) and was created to fulfill the midterm requirements for COSC 426 (Natural Language Processing).


### Files:

- **habitual.txt**: Text file containing meaning-matched AAVE/SAE sentences.
- **preprocessing.py**: Python script that preprocesses `habitual.txt`. 
- **aae_sae.tsv**: Tab-separated file containing semantically matched sentence pairs in AAVE and SAE, generated by `preprocessing.py`.  
- **mp_file_gen.py**: Python script used to generate Minimal Pairs files for probing the language model with AAVE and SAE sentence pairs.
- **mp_file_small.tsv**: The Minimal Pairs file used for our experiment, generated by `mp_file_gen.py`.
- **gpt_config.yaml**: Configuration file for running the Minimal Pairs Experiment in the NLPScholar pipeline.
- **results.zip**: Compressed archive of Minimal Pairs Analyze results, conditioned by words, pairs, and occupations. 
- **predictions.zip**: Compressed archive of Minimal Pairs Evaluate results.  
- **regression.py**: Python script that performs regression analyses, typically using dialect-association scores to predict occupational prestige.
